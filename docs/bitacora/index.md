# Bitácora

Una entrada por sesión de equipo o hito. Corta: qué se hizo, qué se decidió, qué queda.
Quien la escribe va rotando.

Para añadir una entrada, copia la última, cambia la fecha del nombre del archivo
(`AAAA-MM-DD-titulo.md`) y rellénala.
