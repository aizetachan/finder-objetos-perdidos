# Finder — documentación del equipo

Finder es una web para que los objetos perdidos vuelvan a su dueño. Aquí está todo lo que hace
falta para trabajar en ella y el registro de cómo la vamos construyendo.

| Si quieres… | Lee |
|---|---|
| Instalar todo y arrancar el proyecto por primera vez | [Guía del equipo](GUIA-EQUIPO) |
| Darle a tu IA (Claude, ChatGPT, Gemini…) el contexto para empezar | [Prompt de inicio para tu IA](PROMPT-INICIO) |
| Saber cómo se trabaja cada día (ramas, PR, preview) y qué hacer si algo va mal | [Flujo de trabajo](FLUJO-DE-TRABAJO) |
| Entender qué estamos construyendo y quién lleva qué | [Producto](PRODUCTO) |
| Entender de dónde salen los datos que ves en la web | [Entornos](ENTORNOS) |
| Saber por qué algo es como es, o qué está pendiente | [Decisiones y pendientes](DECISIONES) |
| Ver qué se ha hecho en cada sesión | [Bitácora](bitacora/) |

## Dónde va cada cosa

- **Dudas:** en [Discussions](https://github.com/aizetachan/finder-objetos-perdidos/discussions). Si la respuesta le sirve a todos, se pasa a esta documentación.
- **Tareas y cosas rotas:** en [Issues](https://github.com/aizetachan/finder-objetos-perdidos/issues).
- **Esta documentación** se edita como el código: rama → PR. En la documentación basta la aprobación de cualquier compañero.
