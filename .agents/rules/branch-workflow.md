# Regla de ramas para el desarrollo

Todo trabajo debe realizarse **SIEMPRE en una rama secundaria creada a partir de `main`** (por ejemplo, `feature/nombre-corto`).

- Queda estrictamente prohibido realizar cambios o trabajar directamente sobre la rama `main`.
- Antes de iniciar cualquier tarea de código o modificar archivos del proyecto, la IA debe confirmar que el usuario está trabajando en su propia rama `feature/...` y no en `main`.
