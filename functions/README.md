# functions/ — Cloud Functions (esqueleto)

**No se usa en la fase 1** y no se despliega: desplegar funciones exige el plan de pago de Firebase (Blaze).

Esta carpeta va aparte del resto del proyecto a propósito (no es parte del workspace de pnpm), para que
el equipo no tenga que descargar sus dependencias. Quien la necesite:

```bash
cd functions
npm install
npm run build
```
